# 对公众开放，任何人都能用 Google 或 GitHub 登录

系统不再只供自己和小圈子使用，而是部署到公网，任何人都能用 Google 或 GitHub 登录，不需要邀请码，也没有审核。这取代了 ADR-0003 里「只供自己和小圈子使用」这一条。我们接受由此带来的风险：剧情库没有许可证，音色是未经授权的粉丝模型，现在它们会通过角色的回复间接地提供给陌生人。访问密钥整个去掉，不做迁移，因为还没有部署过，也就没有老用户。

## Considered Options

- **公网可访问，但注册要邀请码或审核**：曝光面更小，但每个新用户都要人工处理。
- **完全开放，同时换成授权音色或不再回忆原文剧情**：风险最低，但会失去角色「像本人」的核心体验。
- **保留访问密钥，作为第三种登录方式**：多一个攻击面，而且没有老用户需要它。

## Consequences

- ADR-0003 中不变的部分继续有效：剧情库、镜像缓存不提交，不对外开放剧情查询接口。音色改为可以公开，见 ADR-0003 的 2026-09-27 修订。
- 费用默认全部由部署者承担，用户也可以为 LLM、语音合成、语音识别自带密钥。限额，加上「GitHub 账号注册满一年、Google 邮箱已验证才能登录」，是防止被刷的全部手段，没有全站总预算的上限。
- 登录由后端完成：FastAPI 处理 OAuth 回调，会话存在数据库里，通过 httpOnly cookie 保持登录状态，前端只是一层同源代理。登录凭证不放在 localStorage，这样即使出现 XSS 也偷不走。
- 国内登录方式（QQ、bilibili 等）以后再说。在那之前，访问不了 Google 和 GitHub 的用户无法登录。
- 用户可以删除自己的全部数据，而且是真删。2026-10-03 修订：备份里的副本要等这些备份过期才消失，最多 30 天，见 ADR-0012。
- 2026-10-21 修订：删除提交后就回复用户。之后的 `wal_checkpoint(TRUNCATE)` 只等约 100 ms：有读事务开着（比如备份正在导出）没能做完，就隔几秒再试，直到做完；超过约 10 分钟仍未做完，记一条 error；服务启动时先补做一次。所以 WAL 里的旧页通常几秒内清掉，最迟在下一次做完 checkpoint 时清掉。原来是一直等到做完，碰上长的读事务就挡住所有写入最多 30 秒，等满放弃时也不报错，见 ADR-0028。
