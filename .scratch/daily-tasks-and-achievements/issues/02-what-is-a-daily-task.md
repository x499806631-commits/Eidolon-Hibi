# 02: 拍板：每日任务是什么

Type: grilling
Status: resolved
Blocked by: 01

## Question

- **叫什么**：「每日任务」是暂定名。要不要借世界观写成某个角色发的委托（例如事务员七草はづき，重置卡插画画的就是她），还是就叫系统的任务。定了写进 `GLOSSARY.md`。
- **每天几项**，固定的还是从池子里抽；北京时间 0 点换（和抽奖一样）。没做完的过了一天是作废还是保留。
- **今日偶像**：要不要每天指定一位偶像，任务围绕她；每个用户各抽各的还是全站同一位；冷却中的偶像排不排除（隐藏只存在浏览器里，服务器排除不了）；一位偶像都没聊过的新用户怎么办。
- **什么算完成**：只用服务器能核实的事。候选有：和某位偶像有一个回合、接通一次通话、送一次礼、和几位不同的偶像说话。
  - 通话任务会让人为了做任务打电话，花的是部署者的语音识别和语音合成，要不要放进来。
  - 自带密钥的回合算不算（`messages` 不区分，见地图 Notes）。
  - 冷却中、被她结束的对话里的事算不算。
  - 不做「给某位偶像加几次好感」这类任务（会变成讨好判断模型，没有判断模型时也做不了）：确认一下。
- **完成怎么记**：动作发生时另记一条，还是读取时去查今天的回合、通话、送礼（删掉历史对话会让已完成的变回没完成）。
- **领奖**：做完自动到账，还是要用户来点一下领取。

## Answer

2026-10-20 和用户拍板：

- **叫什么**：系统面板，叫「每日任务」，单项叫「任务」；不借七草はづき或别的角色的口吻（事务员不是角色，应用里只有角色开口）。已写进 `GLOSSARY.md`「好感度与礼物」。
- **不做今日偶像**：任务不点名任何角色，只和一位喜欢的角色往来也能全部做完。
- **固定三项，天天一样**，不从池子里抽：
  1. 和角色有一个回合（任意一位）；
  2. 送出一件礼物；
  3. 和角色们一共有 10 个回合（默认限额每小时 60 个回合，不会撞上）。
  不放接通通话（逼人为了任务打电话、花部署者的语音费用、挡掉没有麦克风的用户；通话里的回合照样算回合）、抽一次奖（拿抽奖换抽奖）、和几位不同的角色说话（只和一位往来的用户做不到）。
- **换天**：北京时间 0 点换新，没做完的作废，不留缓冲。回合按记下的时间（她说完的时候）算哪天，送礼按送出的时间。
- **怎么记**：动作发生时另记进度（回合记下、礼物送出时加一），不在读取时去数 `messages`、`calls`、`conversation_events`；删历史对话不会让做完的变回没做完，导入数据包带来的记录不算。
- **领奖**：做完自动到账，没有领取按钮，所以不存在「做完没领、0 点作废」。到账时怎么提示交给原型票。
- **什么算**：服务器成功记下的回合和送礼都算，包括自带密钥的回合、通话里的回合、冷却中送的礼。失败、被拒的回合不留记录，不算。
- **不做「给某位角色加好感」这类任务**：任务只看用户做了什么，不看好感度怎么变。
- **开关**：「好感度和礼物」关着（或没配判断模型）时不记任何进度；当天中途打开的，从打开那一刻起算。
- **数据包与删除**：进度不进数据包（同好感度、礼物、抽奖次数），删除用户时随之删除。

留给「拍板：每日任务的奖励」：每项给什么、给多少，要不要「全部完成」的额外奖励。
