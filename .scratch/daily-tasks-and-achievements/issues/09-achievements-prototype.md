# 09: 原型：成就放在哪里、长什么样

Type: prototype
Status: resolved
Blocked by: 05, 08

## Question

- 成就放在哪里：礼物页每日任务下面、每位角色的页面（对话列表或她的资料）、统计页旁边，还是单独一页。按角色的有 28 套，按所有角色合起来的有四个，怎么排。
- 没解锁的成就看不看得见、门槛和当前进度要不要显示。
- 解锁那一下长什么样：同每日任务只在导航上一个点、不弹提示条，还是不一样；上线补算一次解锁一大批时怎么办。
- 被隐藏的角色（隐藏只存在浏览器里）她的成就要不要照样显示。
- 宽屏、手机都要看；文案要少。

## Comments

- 来自「拍板：成就的奖励」：每个阶段解锁时自动到账，第 n 阶段给 n 次抽奖；集齐一位角色（她按角色算的阶段全部解锁）再给 1 张重置卡，每位角色最多一次。原型要定：没解锁的阶段要不要事先显示奖励（Hecker 建议出乎意料，但「抽奖 ×n」写在旁边和每日任务一致）；集齐和拿到重置卡那一下怎么表达；上线补算一次到账几十次抽奖时怎么让用户看出来是成就给的。

## Answer

2026-10-20 用户看过原型（`prototype/achievements` 分支，已推到 origin；`?ac=A|B|C` 切换，提交 123a584），拍板：**位置用 B，再加上 A 的「礼物」上的点**。

- **按角色的成就放在她的对话页**：更多菜单最后加一项「成就」，打开面板（用她的颜色，宽屏 Dialog、窄屏照「历史对话」用 Drawer），列她的四个成就，最后一行「集齐」带「重置卡 ×1」，集齐了打勾。不做头像墙，不放统计页，不单独成页。
- **合起来的四个放在礼物页**：每日任务下面一小节「成就」，四行（往来过的角色、到过亲密的角色、来过的天数、抽过的奖）。
- **每一行**：名字，阶段点（解锁的实心、没解锁的空心），下面一行只写下一个阶段：「420 个回合 / 1000 个回合」，档位类写「下一个：亲密」，全部解锁写「全部解锁」；右边写下一阶段的奖励「抽奖 ×n」，全部解锁就不写。不把每个门槛都列出来，也不藏起来。
- **解锁那一下**：
  - 在她的对话页上解锁她的阶段：页首好感度标识左边跳出奖杯和「+n」（n 是到账的抽奖次数），约 3 秒收起（照顾减少动态）；更多菜单键右上角一个点，菜单项「成就」后面一个点，打开面板就消失；面板里新解锁的那一行名字旁一个点。
  - **导航「礼物」上一个点**（用户看原型时加的，取自 A）：成就到账了抽奖次数（或重置卡）时出现，和每日任务的点是同一个点、同一个意思（「有新到的抽奖次数」），进了礼物页就消失。在别的角色的页面、通话里、礼物页以外解锁的，都靠这个点发现。
  - 礼物页那一小节里合起来的成就新解锁时，名字旁一个点，离开礼物页算看过。
  - 不弹提示条。
- **上线补算不另外说明**：补出来的阶段照常到账，「礼物」上出点，对话页的更多菜单上出点，不加说明条、不弹窗。
- **隐藏的角色照常**：隐藏只管对话列表，她的成就照样记、照样在她的对话页里；合起来的成就也照常算她。
- **集齐**：她的面板最后一行，没集齐是空圈加「集齐」和「重置卡 ×1」，集齐了是勾加「集齐了」，到账那一下同上。

留给写规格时定：

- 「看过」记在哪里：更多菜单和面板上的点、礼物页那一小节的点，只记在这台设备上（像公告已读），还是服务器记；和每日任务的「礼物」点一起定。
- 通话层展开时在她的页面上解锁（通话里的回合、通话时长）：页首被通话层盖着，奖杯要不要等通话层收起再跳，还是只留点。
- 读屏名字：奖杯（「成就，抽奖 +2」）、更多菜单键带点时。
