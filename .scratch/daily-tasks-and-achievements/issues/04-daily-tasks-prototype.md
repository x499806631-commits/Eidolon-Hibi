# 04: 原型：每日任务放在哪里、长什么样

Type: prototype
Status: resolved
Blocked by: 02, 03

## Question

- 每日任务放在哪里：礼物页（抽奖台旁边）、对话列表、单独一页，还是导航里新加一项。
- 从任务怎么一步到能做它的地方（对话列表、礼物页）。
- 有没做完的任务时，导航和 dock 上要不要提示（参考搭话的小圆点）；奖励是做完自动到账的，没有领取按钮。
- 做完一项、奖励到账的那一下长什么样（多半是在对话页或礼物页上发生的）；全部做完以后的样子。
- 宽屏、手机都要看；文案要少。

## Comments

- 来自「拍板：每日任务的奖励」：三项任务各给 1 次抽奖，没有「全部完成」的额外奖励；任务面板每项写「抽奖 ×1」、做完打勾。抽奖台的次数只有一个总数、不标来源，任务给的可以超过 7。

## Answer

2026-10-20 用户看过原型（`prototype/daily-tasks` 分支，已推到 origin；`?dt=A|B|C` 切换，提交 87e840b），拍板：**位置用 A，提示方式用 B**。

- **放在礼物页**，抽奖台正下方一节「每日任务」，有重置卡时重置卡条排在它下面，再下面是「我的礼物」。不放对话列表，不在页首加按钮，导航里不加一项。
  - 标题行：「每日任务」、做完几项（「1/3」），右边一句「0 点换新」（北京时间 0 点按制作人的时区写，和抽奖台的「明天 00:00」同一个写法）。
  - 三行任务：没做完是空圈，做完是勾、字变淡并划掉；第三项没做完时带「3/10」；每行右边「抽奖 ×1」。没做完的回合任务旁边「去对话」（去对话列表），送礼那项在背包里有礼物时旁边「挑一件」（滚到「我的礼物」）。刚做完的那一项打勾时弹一下（照顾减少动态）。
  - 三项都做完：整节收成一行，一个勾、「每日任务都做完了」、「0 点换新」。
  - 宽屏和手机同一个版式（礼物页本来就是这样）。
- **做完时不弹提示条**（不用 A 的那条顶上提示）：做完一项、次数到账时，导航栏和 dock 的「礼物」图标右上角一个点，和「对话」上的点一个样子（6px、`bg-foreground`、不用她的颜色）；进了礼物页就消失。在礼物页上做完的（送礼）不出点，那一节当场打勾。通话里做完的也一样，只是点出现。
- **没做完时导航上什么都不标**：点只说「有任务给的抽奖次数到账了」，不催人去做任务（调研里的义务感、挫败感）。

留给写规格时定：

- 「礼物」上的点怎么算「看过」：只记在这台设备上（像公告的已读），还是服务器记；读屏名字（例如「礼物，有新到的抽奖次数」）。
- 抽奖台在次数超过 7 时的样子：原型里 7 个点全亮、后面写「+2」，但下面那句说明还是「已攒满 7 次，抽掉之前不会再发」，要改成说得通的写法。
- 好感度和礼物没开放时这一节和点都不出现（地图已定），礼物页整页本来就是「礼物暂时没有开放」。
