# 05: 拍板：成就是什么、怎么算

Type: grilling
Status: resolved
Blocked by: 01

## Question

- **叫什么**：「成就」是暂定名，定了写进 `GLOSSARY.md`。
- **成就清单**：issue 里提到的候选有和某位偶像的回合数、通话时长、养到亲密的偶像有几位。还有哪些；哪些按某一位偶像算，哪些按所有偶像合起来算。
- **分阶段**：一个成就分几个阶段，每个阶段的门槛。
- **只算这个部署里产生的记录**：数据包导入的记录和这里产生的分不开（见地图 Notes，ADR-0025 说数据包可以伪造）。是给导入的记录补上来源标记，还是不去数现有的记录，改成每次动作发生时另记一份成就进度。
- **删掉历史对话后成就不掉**：解锁了就一直在。要不要连进度也不受删除影响。
- **老用户**：上线那天已经达标的，是一次全部解锁（连奖励一起给），还是从上线那天起才开始算。
- **好感度档位类的成就**：档位会下降（说错话、冷却），升到过亲密就算，还是要求现在仍是亲密；重置卡把她拉回正常值后怎么算。

## Answer

2026-10-20 和用户拍板：

- **叫什么**：「成就」，一个成就分几个「阶段」，每个阶段解锁一次。不叫奖杯、徽章、称号、里程碑、羁绊（称号在偶像大师里是展示用的奖品，留给奖励票）。已写进 `GLOSSARY.md`「好感度与礼物」。
- **怎么记**：动作发生时另记累计进度，同每日任务，不在读取时去数 `messages`、`calls`、`conversation_events`。删历史对话不会收回解锁，进度也不倒退；上线后导入的数据包不算；「好感度和礼物」关着时不记；进度不进数据包，删除用户时随之删除。
- **成就清单**（八个）：
  - 按每一位角色算（每位一套）：和她的回合数；和她接通通话的累计时长（从接通算起）；送她的礼物件数；她的好感度到过的档位。
  - 按所有角色合起来算：往来过几位角色（和她至少一个回合）；到过亲密的角色有几位；来过几天（那天至少一个回合或送过一次礼，累计、不要求连续）；抽过几次奖（不看抽到什么）。
  - 不放：连续天数（错过的挫败、义务感）；稀有度、集齐礼物（运气，种类由维护者加、门槛会变）；搭话、照片（她主动的、看部署配置）；不该说的话、冷却（负面）；合起来的总回合数、总通话时长（和按角色的重复）。
- **阶段和门槛**（常量，可调；调了不收回已解锁的阶段）：

  | 成就 | 算法 | 阶段门槛 |
  |---|---|---|
  | 和她的回合数 | 每位角色 | 10 / 100 / 300 / 1000 / 3000 |
  | 和她通话的累计时长 | 每位角色 | 10 分钟 / 1 小时 / 5 小时 / 20 小时 |
  | 送她的礼物件数 | 每位角色 | 1 / 10 / 30 / 100 |
  | 她的好感度到过 | 每位角色 | 亲近 / 亲密 |
  | 往来过几位角色 | 合起来 | 3 / 10 / 28 |
  | 到过亲密的有几位 | 合起来 | 1 / 3 / 10 |
  | 来过几天 | 合起来 | 7 / 30 / 100 / 365 |
  | 抽过几次奖 | 合起来 | 10 / 50 / 200 / 500 |

- **档位类到过就算**：升到那一档的那一刻解锁，之后说错话掉下来也不收回。重置卡只把低于信任的拉回正常值，碰不到亲近、亲密，不影响。
- **老用户**：上线时从现有记录一次补算，能算的都算：每位角色的回合数、通话时长、送礼件数，往来过几位，来过几天，档位看 `messages.affinity` 的历史档位加现在的值。补算会连上线前导入的记录一起算，只此一次。抽奖不留按用户的记录，从 0 开始。补出来的阶段直接解锁、奖励照给（给多少交给奖励票）。
- **一天按北京时间**：「来过几天」按北京时间划天，同每日任务和抽奖，不按制作人档案的时区（统计才按那个）。
- **角色名单**：新加的角色自动有一套按角色算的成就；「往来过几位」最高一档写死 28，以后加了角色再看要不要加阶段。
- **她不知道**：成就是系统记下的事，解锁不留对话事件，她不会提起。

留给「拍板：成就的奖励」和「原型：成就放在哪里、长什么样」：每个阶段给什么，上线补算一次给出的量，怎么到账、怎么展示。
