# 08: 拍板：成就的奖励

Type: grilling
Status: resolved
Blocked by: 05

## Question

- 每个阶段给什么：抽奖次数、礼物、重置卡，还是什么都不给、只展示（调研：外在奖励会挤掉乐趣，Hecker 建议成就奖励出乎意料、传达信息）。地图 Notes 已定只给背包里的东西，不直接加好感度。
- 给多少：各阶段一样，还是越往后越多；按角色的成就有 28 套，总量要算一遍。
- 「集齐一类」的额外奖励要不要（例如某位角色的成就全部解锁）。
- 到账：解锁时自动到账（同每日任务），还是要用户去领。
- 上线补算一次给出的量：老用户可能一下解锁十几个阶段，要不要封顶或折算。
- 抽奖类成就拿抽奖换抽奖：「抽过几次奖」给抽奖次数会不会自己喂自己。

## Answer

2026-10-20 和用户拍板：

- **每个阶段只给抽奖次数，按阶段序号递增**：第 n 阶段给 n 次，例如「和她的回合数」五个阶段依次 1 / 2 / 3 / 4 / 5 次。按角色的每位 38 次（回合 15、通话 10、送礼 10、档位 3），28 位 1064 次；合起来的 32 次（往来 6、亲密 6、来过几天 10、抽奖 10）；一辈子最多 1096 次。作对比，每天自动发加每日任务做满一个月约 120 次，成就不是抽奖次数的主要来源。给多少写成常量，可调。不给指定礼物（要有人挑、礼物会增加）、不给称号之类的展示品（现在没有这种东西）。
- **集齐一位角色给 1 张重置卡**：某位角色按角色算的阶段全部解锁（叫「集齐」：3000 个回合、20 小时通话、100 件礼物、到过亲密），最后解锁的那个阶段除了照常的抽奖次数，再给 1 张重置卡。每位角色这辈子最多 1 张：以后加了阶段、又不算集齐了，再解锁也不给第二张。合起来算的成就不给重置卡（「来过 365 天」也不破例，规则保持一句话）。其他「集齐一类」的额外奖励不设。重置卡每日任务不给（天天能拿就让冷却失去分量），这里能给是因为集齐要几个月甚至一年，重度用户一辈子多半一两张。
- **自动到账，不用领**：同每日任务。怎么让用户发现交给「原型：成就放在哪里、长什么样」。
- **上线补算照给，不封顶、不折算**：补出来的阶段按上面全额一次到账，集齐的照给重置卡。估一个用了两个月的活跃用户约补 40 次抽奖。
- **不受 `MAX_DRAWS`（7）约束、不分来源**：同每日任务，和其他次数合成一个总数。
- **「抽过几次奖」照样给抽奖次数**：10 / 50 / 200 / 500 次时给 1 / 2 / 3 / 4 次，最多是抽掉次数的 10%，转不起来；「送她的礼物件数」同理。
- **门槛调低时**：已经过了新门槛的用户在下一次相关动作发生时解锁、到账，不另跑补算。
- **好感度提升卡不做**：用户提议过一个只从成就得到的「好感度提升卡」。不做：违反地图 Notes「奖励不直接加好感度」；集齐时用户手里抽奖次数和礼物早已足够把任何一位送到亲密（正常值到亲密约 35 点、约 10 次抽奖），最难拿的反而最没用；还会直接解锁档位类成就、绕回来给抽奖次数。合乎原则的版本是「成就专属礼物」（送给她、留送礼记录、她知道），这一轮也不做，记进地图 Out of scope。
