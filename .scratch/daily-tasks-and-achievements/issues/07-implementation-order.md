# 07: 拍板：两份规格的实现顺序和分支衔接

Type: grilling
Status: resolved
Blocked by: 02, 03, 04, 05, 06, 08, 09

## Question

- 定图时已定：先每日任务、后成就，各对应一个 `feat/` 分支。每日任务上线后看多久的效果再开成就的分支。
- 两份规格共用的东西（例如「给用户发奖励」的入口、奖励到账的提示）放进先做的那份，后一份怎么接。
- 规格目录（`.scratch/daily-tasks/`、`.scratch/achievements/`）在开工时从计划分支取出；词汇表跟哪个分支走。
- 每份规格拆成几张票、谁先谁后。

## Comments

- 来自「原型：成就放在哪里、长什么样」：导航「礼物」上的点由每日任务和成就共用，意思都是「有新到的抽奖次数」，放进先做的每日任务规格，成就规格接上去；礼物页的顺序是抽奖台、每日任务、成就（合起来的四个）、重置卡、我的礼物。
- 来自「拍板：后台、看板和对外文档」：要按规格分的有——看板一小节（两种新运行记录：任务的跟每日任务、阶段的跟成就；看板那一节先上的规格建、后一份往里加格）；隐私政策「每日任务和成就」一条和「运行记录」补的半句、使用条款补的那句、`configuration.md`/`deploy.md`/`data-package-format.md`、README 半句，都要在两份里各写各的那一半或第一份先写全；统计页「成就」一节和礼物页截图重拍只在成就规格里；两条公告草稿各在各的规格里。

## Answer

2026-10-20 和用户拍板：

- **先后**：先做每日任务，再做成就。每日任务合进 main、部署以后马上开成就的分支，不另外等一段时间看效果（成就的门槛、奖励和补算都不依赖每日任务的数据）。
- **分支和规格目录**（照「好感度和礼物」那张地图的做法）：
  - 两份规格都在计划分支 `feat/daily-tasks-and-achievements` 上写好；计划分支只放计划，不合进 main。
  - `feat/daily-tasks` 从 main 开，开工时从计划分支取出 `.scratch/daily-tasks/` 和这张地图 `.scratch/daily-tasks-and-achievements/`。
  - `feat/achievements` 等每日任务合进 main、部署以后再从 main 开，只取 `.scratch/achievements/`，不叠在每日任务的分支上。成就规格开头写明：第一张票先对照 main 上每日任务实际做出的接口，对不上就在票里改。
- **词汇表**：计划分支上 `GLOSSARY.md` 的改动（「每日任务」「成就」两条，「抽奖」「重置卡」「统计」三条的改写）整份跟每日任务分支走；成就、统计两条比功能早上线一段时间，能接受。
- **共用的后端放进每日任务**，成就接上去：
  - 发奖励的入口：`gifts.py` 里公开的「给某位用户加 N 次抽奖」，和动作在同一个事务里、持锁。每日任务只用抽奖次数；加 M 张重置卡的参数由成就分支补，不预先做。
  - 记进度的接缝：回合记下、礼物送出两处只调用一个「发生了什么」的入口，由它分给每日任务；成就分支往这个入口里加自己那份，并补上通话结束、抽奖、档位变化几处调用，不在回合、送礼的代码里再并排加一行。入口的名字和签名写规格时定。
- **共用的前端放进每日任务**：导航「礼物」上的点（「有新到的抽奖次数」）由每日任务建，成就接上；「看过」记在哪里写每日任务规格时定，成就的更多菜单、面板上的点照它。
- **看板、配置页说明和对外文档各写各的一半**，不提前写还没上线的东西：
  - 看板：每日任务分支建这一小节，标题先叫「每日任务」、三格；成就分支加三格，标题改成「每日任务和成就」。
  - 隐私政策：每日任务分支先加一条「每日任务」，「运行记录」补做完了哪项任务；成就分支把那一条改名「每日任务和成就」、补上成就，「运行记录」补解锁了哪个阶段。「最后更新」日期改两次。
  - 使用条款那一句、`docs/configuration.md`、`docs/deploy.md`、`docs/data-package-format.md`、README 三语的半句、配置页「好感度和礼物」卡的说明，都照同样的办法分。
  - 只在成就规格里：统计页「成就」一节、礼物页截图重拍。两条公告草稿各写在各自的规格里。
- **拆票**：张数交给 `/to-tickets`，规格里只写顺序：后端先做（记进度、到账，连同运行记录和看板），再做界面，对外文档和公告草稿放最后一张。大致是：
  - 每日任务约 3 张：记进度、到账、接口和看板；礼物页那一节和导航上的点；对外文档。
  - 成就约 5 张：记进度、解锁、到账；上线补算；她的对话页面板和奖杯；礼物页那一小节和统计页；对外文档和截图。
- **上线**：
  - 每块合进 main 后各自部署，不加新开关，跟着「好感度和礼物」的开关走。
  - 成就部署前手动备份数据库（新表、补算会给所有用户发抽奖次数）。补算只跑一次：重复部署不会再发一遍，写进成就规格。
  - 两条公告都是部署后由用户在后台发。
